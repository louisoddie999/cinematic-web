# Cinematic Web Experiments

A collection of creative-technology studies spanning scroll-driven storytelling, canvas frame sequences, motion systems, image-generation direction, and interactive film concepts.

## Selected experiments

| Project | Focus |
|---|---|
| `CINEMATIC-SCROLL-DEMO/` | Next.js scroll experience with a DPR-aware canvas, Lenis smooth scrolling, and a timeline-driven narrative |
| `ACTION-TRAILER/` | Browser-based cinematic treatment and shot-planning interface |
| `GPT-IMAGE-2-CINEMATIC/` | Image-direction studies, prompt systems, and visual research |
| `NINJA-FIGHT-BLOCKBUSTER/` | Action-sequence continuity and shot-design experiments |
| `TACTICAL-LEAP-CINEMATIC/` | Tactical motion and transition studies |

## What this repository demonstrates

- Translating cinematic beats into web interaction states
- Frame-sequence playback on responsive canvas
- Device-pixel-ratio-aware rendering
- Smooth-scroll orchestration and reduced-motion consideration
- Art-direction systems for generated imagery
- Shot lists, continuity planning, and prompt iteration
- Packaging research, prototypes, and implementation notes into reusable systems

## Run the scroll demo

```bash
git clone https://github.com/louisoddie999/cinematic-web.git
cd cinematic-web/CINEMATIC-SCROLL-DEMO
npm install
npm run dev
```

Then open `http://localhost:3737`.

## Notes

This is an experiment library rather than a single production application. Some folders are static HTML treatments or creative-development artifacts; the scroll demo is the primary runnable web project.
